# Audio credits

All audio in this folder is original and synthesised from scratch by `src/make_audio.py`
(numpy + scipy, fixed seeds). No external recordings, samples, sample packs or
impulse responses were used; the reverb impulse responses are generated in code too.

| File | Source | Author | Licence |
|---|---|---|---|
| all `*.ogg` | `src/make_audio.py` | GameNet project | owned by the project |

External downloads: none (`_downloads/` was not created).

## School set (`school/`)

All audio in `school/` (the Home Time haunted-school set) is also original and procedurally
synthesised from scratch by `school/src/make_school_audio.py` (numpy + scipy, fixed seeds),
reusing the primitives in `src/make_audio.py`. The children's choir, the hymn tune, the voices
(murmur, whisper, shriek, snore), and every room impulse response are generated in code. No
recordings, samples, sample packs, impulse responses, or copyrighted melodies were used.

| File | Source | Author | Licence |
|---|---|---|---|
| all `school/*.ogg` | `school/src/make_school_audio.py` | GameNet project | owned by the project |

External downloads: none.
