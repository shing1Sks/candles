# GameNet

A small, grey, three-quarter top-down horror maze.

You are a small kid. You must blow out the candle in the corner of every room.
A monster hunts you. It is as fast as you are, but only you fit through the small gaps.

Status: design in progress. Nothing is built yet.

The earlier prototypes (forest, school, The Long Way Home) are kept under the git tag `archive/before-maze`.
